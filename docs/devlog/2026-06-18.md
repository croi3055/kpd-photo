# Dev Log - 2026-06-18

## Changed

- Replaced focus-only inline rename commit with an outside-click event monitor so clicking the viewer or another non-focusable area commits the rename.
- Added support for opening organizer windows from multiple dropped image or video files, while preserving folder drops.
- Updated welcome and onboarding copy to say folders, photos, or videos can be dropped.
- Added a fresh session identity to each organizer input so reopening the same folder does not reuse stale closed-window viewer state.
- Added a dedicated "folder browsed" completion screen when advancing past the last media item, with a right-arrow hint to return to the first item.
- Changed default media ordering to file modification time, newest to oldest, with a persistent toolbar toggle for oldest to newest.
- Added fixed square trash thumbnails plus arrow-key focus, Enter selection, Shift+arrow range selection, and Space preview.
- Replaced the media sort toolbar clock icon with a clearer A-Z/Z-A style icon.
- Updated trash Shift+arrow selection to recompute the active range so moving back cancels temporary selections.
- Updated trash preview so arrow keys switch previewed items and the preview sheet no longer shows an OK button.
- Updated trash preview so Space closes the preview sheet.
- Fixed trash range selection so the anchor item is not stuck selected when it was only part of a temporary Shift+arrow range.
- Updated sort toggling to jump to the first item in the newly selected order so the visible browser image changes immediately.
- Updated user-facing deletion copy so the in-app state is called Delete Queue and only confirmed file moves refer to the system Trash.
- Shortened deletion copy so confirmed moves are described as delete actions and the in-app holding area is called Trash.

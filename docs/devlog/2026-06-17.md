## Decisions

- The app should read photos directly from Finder folders.
- The app should not import photos into an app-managed library.
- The app should not copy originals by default.
- The app should not generate persistent image caches by default.
- Destructive operations should be planned first and confirmed before execution.
- Deleted files should go to the macOS Trash.
- The UI should use native macOS patterns.

# Dev Log - 2026-06-21

## Changed

- Added centralized window coordination for welcome and organizer windows.
- Organizer windows now use the opened folder name as their window title.
- Opening folders now validates supported media before creating an organizer window.
- Dropping a folder that is already open now shows a prompt instead of opening a duplicate organizer.
- Organizer windows now show a drag-target overlay while folders or media are dragged over them.
- App trash now shows photo/video counts at the top of the review sheet.
- App trash Select All toggles to Deselect All, and Restore Selected changes to Restore All when all trash items are selected.
- Settings now displays `↑` as the primary Add to Trash shortcut.
- Duplicate and empty-folder drops now show in-window non-blocking notices instead of modal alerts.
- Organizer drag feedback now blurs the viewer area with a glass-style drop hint instead of turning the surface blue.
- Folder picker title and message now use app-managed localized strings.
- App commands now replace irrelevant default menu groups to reduce English-only menu items in Chinese mode.
- Edit menu pasteboard commands now use app-managed localized Cut/Copy/Paste/Select All items.
- App trash footer now keeps Delete All visible, shows Delete Selected only when needed, and displays keycap-style hints for Select All and Restore.
- Close-with-trash confirmation now uses Discard Changes/撤销更改 for the non-destructive close path.
- Welcome drop hot zone now uses a fixed 3:2 area with even default outer margins.
- Reduced the welcome window and drop hot zone size by roughly one third.
- Empty-folder and duplicate-folder notices are now more prominent warning-style toasts.
- Welcome drop hot zone and welcome window now use a compact square layout.
- Removed the Select All keycap hint in the app trash footer to avoid button truncation.
- Updated app trash footer actions: Restore All appears with no selection, Select/Deselect All appears only after selection starts, Delete Selected uses `D`, and Delete All keeps `Command+D` as a tooltip-only shortcut.
- Replaced the close-with-trash alert with a small closable macOS confirmation window so the red window close button cancels the close prompt.
- Centered the app trash photo/video summary.
- Enlarged the organizer drop overlay hint.
- Added runtime localization for top-level app menus and removed unused Format/Services menu items.
- Added a focused image/video context menu with Show in Finder, Open in Preview, and AirDrop actions.
- Added `Esc` as an organizer-window close shortcut while preserving the pending-trash confirmation flow.
- Changed undo shortcuts to `Z` and `Down Arrow`.
- Iterated on the close-with-trash confirmation window so it uses a small closable macOS window, keeps only the red close control, pauses organizer shortcuts while open, and returns to the welcome window after either destructive or non-destructive completion.
- Updated the close-with-trash confirmation buttons to use compact text-sized capsule styling with Delete and Close as the primary blue action.
- Recorded follow-up UI work to align close confirmation button styling with the welcome screen button style.

## Fixed

- Empty folders no longer turn the welcome window into an organizer window.
- Left/Right Arrow browsing now takes precedence over video-player scrubbing in the organizer.
- Shift+arrow range selection in the app trash can select and cancel across Shift key releases.
- Closing one organizer window no longer creates an extra welcome window while other organizer windows remain open.
- App commands are registered once for the scene group to avoid duplicate Settings menu items.
- Organizer windows opened from another organizer now get the folder name as their title.
- Closed organizer sessions now unregister their open-folder key so the same folder can be opened again later.
- Discarding close-time pending trash changes now restores app trash items to the browsing list and closes without deleting files.
- Organizer windows now also unregister through `NSWindow.willCloseNotification`, preventing stale duplicate-folder state after close.
- Opening a valid folder after first dropping an empty folder now closes the welcome window instead of leaving it behind.
- Closing an organizer via `Esc` now restores the welcome window.
- Main organizer browsing shortcuts no longer remain active while the close-with-trash confirmation window is open.

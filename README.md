# KPD

**Ongoing — 持续开发中，暂不提供应用下载。**

KPD = **Keep / Pending / Delete**，一个直接整理 Finder 文件夹的原生 macOS 照片与视频工具。

打开文件夹，逐张浏览，为照片和视频决定去留。不需要导入图库，也不需要一次做完所有决定。

## 三种决定

- **Keep · 保留**：明确想留下的内容，先放入应用内的保留箱，确认后移入原文件所在目录下的 `Keep/` 文件夹。
- **Pending · 待定**：还没想好，就先跳过。文件留在原处，下次打开同一个文件夹时仍会出现在待整理列表中，不需要另外建立“待定”文件夹。
- **Delete · 删除**：先放入应用内的垃圾桶，复查后再执行删除。文件会移入 macOS 系统废纸篓，不会被直接永久删除。

## 基础使用流程

1. **打开内容**：将 Finder 中的文件夹、照片或视频拖入 KPD，也可以点击“打开文件夹”选择要整理的目录。
2. **浏览并决定**：用左右方向键浏览；想保留就按 `↓`，想删除就按 `↑`。暂时不决定时，按 `→` 继续看下一项即可。
3. **复查选择**：打开保留箱或应用内垃圾桶检查已选内容。保留箱里的项目可以“移回待定”，垃圾桶里的项目可以“恢复”，重新回到待整理列表。
4. **确认操作**：在应用内垃圾桶中点击“删除所选”或“删除全部”，会将对应文件移入系统废纸篓。关闭整理窗口时，如果仍有未确认的操作，选择“确认并关闭”会将保留项移入 `Keep/`，并将待删除项移入系统废纸篓；选择“放弃更改”则取消尚未执行的决定。
5. **下次继续**：再次打开原文件夹，尚未决定的照片和视频仍在那里，可以继续整理。

## 常用操作

以下快捷键用于主浏览界面：

| 按键 | 操作 |
| --- | --- |
| `←` / `→` | 浏览上一项 / 下一项，不改变去留决定 |
| `↓` | 将当前项目加入保留箱 |
| `↑` | 将当前项目加入应用内垃圾桶，暂不删除文件 |
| `Z` | 撤销最近一次尚未确认的保留或删除标记 |
| `Delete` | 打开应用内垃圾桶，不是直接删除当前文件 |
| `I` | 显示或隐藏时间信息 |
| `Esc` | 请求关闭整理窗口；有未确认操作时会提示处理 |

未确认的决定和撤销记录只保存在当前会话中，退出应用前请先处理完。已经执行的文件移动或删除不能通过 `Z` 撤销；“放弃更改”也不会撤回已经执行的操作。
